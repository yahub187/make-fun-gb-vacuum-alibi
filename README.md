One line, filed like an incident report: a robot vacuum explains the missed corner — its sensors found a dust-bunny colony, its schedule filed it under 'wildlife conservation,' and its battery declined to die evicting them. The program writes that single line to /output/entry.txt and self-checks it against the 1–200 character gate before writing.

## Run it

```sh
python3 main.py
```
